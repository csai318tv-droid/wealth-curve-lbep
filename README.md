# 부의 곡선 L-BEP 계산기

안유화 「부의 곡선」의 L-BEP(Life Break-Even Point, 인생의 손익분기점) 워크시트를 그대로 옮긴 계산기입니다.

- 월 필수생활비(A′)와 세후 지속가능 월 현금흐름(B)을 적으면 **Life Gap = A′ − B**, **L-BEP 달성률 = B ÷ A′ × 100**, 현재 구간(다섯 구간), 바닥 현금흐름 충당률, 비상 활주로를 계산합니다.
- 보수적·기준·낙관적 세 가지 시나리오로 물가조정 후 미래 생활비와 달성률을 계산합니다.
- 비용곡선과 자산소득곡선을 그려 두 곡선이 만나는 시점을 보여줍니다.
- 새는 돈 절감액의 실제 배분 가능액, 여섯 봉투 합계 점검, ‘오늘의 기록’ 요약 복사 기능이 있습니다.

## 사용

`index.html` 파일 하나로 완결된 앱입니다. 로그인이나 설치 없이 브라우저에서 바로 열립니다.
입력한 숫자는 사용자의 브라우저에만 저장되며 어떤 서버로도 전송되지 않습니다.

## 고지

이 계산기는 교육용 도구이며 투자 권유나 재무 자문이 아닙니다. 세금·연금·보험 등 개별 사항은 전문가와 확인하십시오.
